## TROUBLESHOOTING

### Common Issues

#### 1. RAFCODE-Φ Validation Fails

**Problem**: Missing RAFCODE-Φ signature in core files

**Solution**:
```bash
# Check which files are missing signatures
python3 scripts/validate_rafcode.py

# Add RAFCODE-Φ header to files:
# RAFCODE-Φ-∆RafaelVerboΩ-𓂀ΔΦΩ
```

#### 2. Bitraf64 Format Invalid

**Problem**: Invalid Bitraf64 format in manifest

**Solution**:
```bash
# Generate new Bitraf64
python3 scripts/bitraf64.py encode "RAFAELIA Framework"

# Verify format
python3 scripts/bitraf64.py verify <bitraf64_string>
```

#### 3. Seal Validation Issues

**Problem**: One or more seals not validated

**Solution**:
```bash
# Run seal validator to see which seals need attention
python3 scripts/validate_seals.py

# Address specific seal requirements (see report)
```

#### 4. Workflow Failures

**Problem**: GitHub Actions workflow fails

**Solution**:
1. Check workflow logs in GitHub Actions
2. Run validation scripts locally
3. Fix identified issues
4. Commit and push changes
